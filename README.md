# Análise de Gastos Pessoais

Análise exploratória de gastos pessoais com Python — identifica 
padrões de consumo por categoria, calcula totais mensais e aponta 
o mês de maior gasto.

## Como executar

git clone https://github.com/edu76666/analise-gastos-pessoais
cd analise-gastos-pessoais
pip install -r requirements.txt
jupyter notebook analise.ipynb

## Tecnologias

- Python 3.14
- Pandas
- Matplotlib
